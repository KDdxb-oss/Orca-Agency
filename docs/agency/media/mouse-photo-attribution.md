`mouse-workspace-history.svg` embeds the unmodified photograph with new vector labels, arrows and a background. The resulting visual is licensed CC BY-SA 2.0. This media exception does not change Orca Agency's MIT code license. The photo's author and Logitech do not endorse Orca Agency.

The labels point to the arrows printed on the two side buttons. Mouse driver remapping can change which hardware button sends Back or Forward. Orca uses the command delivered by the device.
